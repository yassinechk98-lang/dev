Politique de signature du code (Code signing policy)

Comment FreeAV.exe est construit et signé · Dernière mise à jour : 12 octobre 2026

Signature de code gratuite fournie par SignPath.io, certificat de la SignPath Foundation.

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Statut : demande en préparation. Les versions actuelles de FreeAV.exe ne sont pas encore signées. Windows peut donc afficher « Windows a protégé votre ordinateur » : voici quoi faire.

Ce qui est signé

Uniquement FreeAV.exe, construit à partir du code source public de FreeAV. ClamAV, que FreeAV peut installer à votre demande, n'est pas fourni par FreeAV : il est téléchargé chez Cisco Talos, sans le module RAR, qui n'est pas libre, et n'est jamais signé par FreeAV.

Le certificat appartient à la SignPath Foundation : une fois signé, FreeAV.exe affichera « SignPath Foundation » comme éditeur, dans l'avertissement de Windows comme dans les propriétés du fichier.

Vérifier la signature

Faites un clic droit sur FreeAV.exe, puis Propriétés, onglet « Signatures numériques » : le signataire doit être « SignPath Foundation », et Windows doit indiquer que la signature numérique est valide. En PowerShell, Get-AuthenticodeSignature .\FreeAV.exe doit afficher le statut Valid. Tant que FreeAV.exe n'est pas signé, cet onglet n'apparaît pas : comparez alors le résultat de Get-FileHash .\FreeAV.exe avec l'empreinte SHA-256 publiée.

Construction

Chaque version signée sera construite automatiquement par GitHub Actions, sur un serveur Windows hébergé par GitHub, à partir du code de la branche main. Avant la publication, les tests passent sous Windows et l'exécutable est essayé pour de vrai : il doit détecter un fichier de test et laisser passer un fichier sain. Chaque FreeAV.exe publié est aussi analysé par Microsoft Defender pendant la construction, après une mise à jour de ses signatures et un contrôle avec le fichier de test EICAR, et le résultat est écrit dans les notes de version. Ce contrôle n'est ni une validation ni une certification par Microsoft. Aucune version signée n'est construite sur un ordinateur personnel, et chaque demande de signature sera approuvée à la main. Les étapes de construction sont publiques : build-windows.yml.

Confidentialité

FreeAV n'envoie aucun fichier ni aucune donnée d'utilisation. Seule exception, le deuxième avis facultatif de Microsoft Defender : sa protection dans le cloud peut envoyer des échantillons à Microsoft, selon les réglages de Windows. FreeAV ne se connecte à Internet que pour :

  • vérifier s'il existe une nouvelle version et la télécharger (github.com, désactivable) ;
  • installer ClamAV si vous le demandez, depuis la publication officielle de Cisco Talos (github.com/Cisco-Talos/clamav), et mettre à jour ses signatures (database.clamav.net) ;
  • télécharger des signatures si vous avez enregistré votre clé abuse.ch (mb-api.abuse.ch).

Tous les détails sont sur la page Confidentialité.

Signaler un problème

Si vous trouvez un FreeAV.exe signé qui n'a pas été construit de cette façon, ou une faille de sécurité, prévenez-nous. Le signalement privé de GitHub n'est pas encore ouvert sur le dépôt : en attendant, ouvrez un ticket sur GitHub intitulé « Sécurité », sans donner de détails, car les tickets sont publics. Un moyen privé vous sera alors proposé pour envoyer les détails.
