Politique de signature du code

Comment FreeAV.exe est construit et signé · Dernière mise à jour : 11 octobre 2026

Signature de code gratuite fournie par SignPath.io, certificat de la SignPath Foundation.

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Statut : en attente de l'accord de la SignPath Foundation. Les versions actuelles de FreeAV.exe ne sont pas encore signées. Windows peut donc afficher « Windows a protégé votre ordinateur » : voici quoi faire.

Ce qui est signé

Uniquement FreeAV.exe, construit à partir du code source public de FreeAV. Les logiciels d'autres éditeurs que FreeAV peut installer à votre demande, comme ClamAV de Cisco Talos, sont distribués tels que leur éditeur les publie et ne sont jamais signés par FreeAV.

Code source et licence

Le code source de FreeAV est public : github.com/yassinechk98-lang/dev/tree/main/antivirus. Il est distribué sous licence GNU General Public License version 3 (GPL-3.0) : chacun peut le lire, le modifier et le redistribuer, à condition que les versions modifiées restent elles aussi libres et open source.

Équipe

  • Auteur et relecteur (committer, reviewer) : Yassine (GitHub yassinechk98-lang)
  • Approbateur des signatures (approver) : Yassine (GitHub yassinechk98-lang)

Les modifications arrivent sur la branche main par des demandes de fusion (pull requests), relues et fusionnées par Yassine.

Construction

Chaque version signée sera construite automatiquement par GitHub Actions, sur un serveur Windows hébergé par GitHub, à partir du code de la branche main. Avant la publication, les tests passent sous Windows et l'exécutable est essayé pour de vrai : il doit détecter un fichier de test et laisser passer un fichier sain. Aucune version signée n'est construite sur un ordinateur personnel, et chaque demande de signature sera approuvée à la main. Les étapes de construction sont publiques : build-windows.yml.

Confidentialité

FreeAV n'envoie aucun fichier ni aucune donnée d'utilisation. Il ne se connecte à Internet que pour :

  • vérifier s'il existe une nouvelle version et la télécharger (github.com, désactivable) ;
  • installer ClamAV si vous le demandez (github.com) et mettre à jour ses signatures (database.clamav.net) ;
  • télécharger des signatures si vous avez enregistré votre clé abuse.ch (mb-api.abuse.ch).

Tous les détails sont sur la page Confidentialité.

Signaler un problème

Si vous trouvez un FreeAV.exe signé qui n'a pas été construit de cette façon, ou une faille de sécurité, prévenez-nous. Le signalement privé de GitHub n'est pas encore ouvert sur le dépôt : en attendant, ouvrez un ticket sur GitHub intitulé « Sécurité », sans donner de détails, car les tickets sont publics. Un moyen privé vous sera alors proposé pour envoyer les détails.
